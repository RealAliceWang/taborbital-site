页签空间站隐私政策

更新日期：2026 年 7 月 26 日

页签空间站是一款本地优先的浏览器标签页管理工具。本政策说明扩展如何处理用户数据，以及用户主动启用账号和云备份时的数据处理方式。

处理的数据

当用户打开新标签页、点击工具栏图标、使用快捷键、点击右键菜单或主动保存标签页时，扩展会读取 浏览器中已打开页签的标题、网址和网站图标，用于展示、保存、搜索和恢复用户的页签收藏。 新标签页右侧面板会列出所有窗口的页签，便于用户整理；这些信息仅在本机内存与本地存储中使用。 用户主动选择「保存并关闭」时，扩展仅关闭已成功保存的普通网页页签。

用户可选择使用邮箱注册云端账号。注册和登录过程中会处理邮箱、昵称、加密后的账号凭据及登录会话； 开发者不会读取用户的明文密码。未注册或未登录时，扩展的本地整理功能仍可正常使用。

为准确说明商店数据类型，扩展处理的数据包括：

  • 个人身份信息：用户主动提供的邮箱和昵称；
  • 身份验证信息：由 Supabase 处理的登录凭据和登录会话；
  • 浏览活动及网站资源：用户当前打开或主动保存的网页标题、网址和网站图标；
  • 用户生成内容：用户创建的空间名、分组名、收藏名称和收藏描述。

数据存储

默认情况下，页签收藏、空间、分组和偏好设置仅保存在用户设备上的浏览器本地存储中。 登录后，只有在用户主动点击「备份到云端」时，扩展才会将当前收藏数据上传；不会自动上传浏览记录。

数据使用目的

上述数据仅用于扩展的单一用途：帮助用户整理、保存、搜索、恢复和跨设备备份浏览器标签页。 邮箱和身份验证信息仅用于账号管理；收藏数据仅用于用户主动使用的本地整理及云备份功能。 扩展不将数据用于广告、行为分析、信用评估或与标签页管理无关的用途。

云服务提供商

账号认证和用户主动上传的云备份由 Supabase 提供存储与处理服务。 数据将存储在本项目选择的 Supabase 服务区域，可能位于中国大陆境外。 Supabase 仅用于账号登录、会话维护和个人备份，不用于广告或用户画像。

数据共享与出售

扩展不会出售、出租用户数据，也不会将数据用于广告、信用评估或与核心功能无关的用途。 除为提供账号和云备份而委托 Supabase 处理外，不会向其他第三方提供用户数据。

权限用途

tabs：读取已打开页签的标题、网址和图标，并支持用户切换、排序、保存、批量打开或在保存后关闭页签。

storage：在本地保存用户创建的空间、分组和网页收藏。

unlimitedStorage：解除本地存储的容量上限，使收藏数量较多的用户不会因配额限制而保存失败。 该权限不会带来任何联网或数据上传行为。

favicon：通过 Chrome 或 Microsoft Edge 的 Chromium 内置接口显示用户已保存网页的官方网站图标。

contextMenus：在浏览器右键菜单中提供「保存到某个分组」入口。菜单仅在用户点击时 读取当前页面或链接的网址与标题，不会在后台扫描页面内容。

Supabase 网络域名：仅在用户注册、登录、退出或主动进行云备份操作时， 连接 Supabase 官方 API 域名完成账号认证和个人数据读写。

数据删除

用户可在扩展中删除单个收藏、分组或全部云端备份。卸载扩展后，Chrome 或 Microsoft Edge 将删除该扩展保存在本地的数据， 但不会自动删除用户此前主动上传的云备份。用户可在卸载前点击「删除云端数据」，或通过联系邮箱申请删除账号及关联数据。

有限使用承诺

页签空间站对从 Chrome 与 Microsoft Edge 扩展 API 获取的数据的使用符合 Chrome Web Store 用户数据政策（包括 Limited Use 要求）以及 Microsoft Edge Add-ons 的适用政策。 这些数据只用于提供用户明确可见的标签页整理、保存、恢复和可选云备份功能。

远程代码

扩展不下载或执行远程 JavaScript、WebAssembly 或其他可执行代码。Supabase SDK 已随扩展本地打包， Supabase 网络请求仅用于账号认证和用户主动发起的数据存储与读取，不会返回或执行远程代码。

政策变更

如数据处理方式发生变化，本政策将同步更新，并在适用情况下征得用户同意。
